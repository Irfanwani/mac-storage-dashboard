No account · No telemetry · MIT licensed

The dashboard

Built like a map, not a menu.

Point it at your disk. It reports what's actually allocated, groups it by category, and shows you where the weight is hiding.

Treemap, not a list

Every folder becomes a tile proportional to its size. Drill from the whole disk down to a single cache folder in three clicks.

Junk in two tiers

Safe means regenerable — caches, logs, build artifacts. Review means your data. Hatched tiles show exactly where reclaimable space sits.

Nothing is automatic

Recommendations arrive with checkboxes. The app never deletes on its own, and irreversible actions always demand explicit confirmation.

In-app cleanup or script

Delete reviewed items right in the dashboard — each one re-validated by id just before removal — or copy the generated shell script and run it yourself.

Honest numbers

A pure-Python scanner counts allocated blocks and de-duplicates hardlinks, so totals match what Finder reports — even where du quietly fails under Full Disk Access.

Permissions, explained

The app requests Full Disk Access itself — so macOS attributes it to the app, not your terminal — and names the folders it still can't see.

Your disk data never leaves this Mac.

No accounts, no sync, no analytics. The dashboard is a page served on your own loopback interface, and it stops when you click Stop.

  • ✓Local by constructionEverything runs at 127.0.0.1 from the app you installed. There is no cloud service to opt out of.
  • ✓Safe by refusalProtected system paths are blocked, sudo-only items are handed to you as a script instead, and every in-app deletion is re-checked right before it happens.
  • ✓Honest about permissionsOne click to the Full Disk Access pane, plus a clear list of what's missing — instead of silently reporting zero.

Install

Two commands, or one.

A self-contained macOS app — move it anywhere, including /Applications. Needs Python 3.9+; runs on Apple silicon and Intel.

Homebrew cask Recommended

Installs the app straight into /Applications and updates with brew upgrade.

brew install --cask irfanwani/tap/mac-storage-dashboard

PyPI (pipx)

Builds the app locally and copies it into /Applications — no Gatekeeper prompt.

pipx install mac-storage-dashboard
mac-storage-dashboard install

From source

Pick up the latest main branch and build the app yourself.

git clone https://github.com/Irfanwani/mac-storage-dashboard.git
cd mac-storage-dashboard && ./build_app.command
▲
First launch with Homebrew macOS will refuse the app because it isn't notarized by Apple yet. Approve it once via System Settings → Privacy & Security → “Open Anyway”, or run xattr -dr com.apple.quarantine "/Applications/Mac Storage Dashboard.app". Repeat after each brew upgrade. The PyPI route builds locally and skips this.
